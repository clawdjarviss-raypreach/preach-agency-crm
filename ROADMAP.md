# Preach CRM — Product Roadmap

> Living document. Last updated: Feb 2026.

## ✅ Shipped

| Feature | Description |
|---------|-------------|
| **Admin Revenue Dashboard** | Daily earnings, trends, creator filter, period comparison, new subs vs rebills |
| **Sales Feed** | Live transaction stream via OF API webhooks |
| **Fan Directory** | Searchable fan database with profile details |
| **OF API Integration** | Webhook-driven real-time sync across 6 accounts |
| **Marketing Manager Dashboard** | Restricted view with role-based access and team management |
| **Chatter Performance** | OM Excel import for attribution tracking |
